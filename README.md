# pty

A small Go package for pseudo-terminals: master/slave pairs on Unix-like
systems, and ConPTY pseudo-consoles on Windows.

## Install

```sh
go get github.com/malivvan/pty
```

## Platform support

| System                              | Pseudo-terminal | ConPTY |
| ----------------------------------- | --------------- | ------ |
| Linux, Android                      | yes             | no     |
| macOS, iOS                          | yes             | no     |
| FreeBSD, NetBSD, OpenBSD, DragonFly | yes             | no     |
| Solaris, illumos                    | yes             | no     |
| z/OS                                | yes             | no     |
| Windows                             | no              | yes    |
| AIX, Plan 9, js/wasm, wasip1/wasm   | compiles only   | no     |

Everything the package cannot do on a given system fails with
`pty.ErrUnsupported`, so portable programs keep compiling and can degrade
gracefully.

## Running a command on a pseudo-terminal

`pty.Start` allocates a pair, connects the standard streams of the command to
the slave end, starts it in a new session with that slave as its controlling
terminal, and hands back the master end:

```go
package main

import (
	"io"
	"log"
	"os/exec"

	"github.com/malivvan/pty"
)

func main() {
	cmd := exec.Command("grep", "--color=always", "bar")

	ptmx, err := pty.Start(cmd)
	if err != nil {
		log.Fatal(err)
	}
	defer func() { _ = ptmx.Close() }() // Best effort.

	go func() {
		_, _ = ptmx.Write([]byte("foo\n"))
		_, _ = ptmx.Write([]byte("bar\n"))
		_, _ = ptmx.Write([]byte("baz\n"))
		_, _ = ptmx.Write([]byte{4}) // EOT
	}()

	_, _ = io.Copy(os.Stdout, ptmx)
}
```

Use `pty.StartWithSize` to resize the terminal before the command starts, and
`pty.StartWithAttr` when the process attributes have to be set up differently.

## An interactive shell

To drive a program as if it were running in the user's terminal, put the local
terminal in raw mode and forward its size to the pty:

```go
cmd := exec.Command("bash")

ptmx, err := pty.Start(cmd)
if err != nil {
	return err
}
defer func() { _ = ptmx.Close() }() // Best effort.

// Keep the pty the same size as the local terminal.
winch := make(chan os.Signal, 1)
signal.Notify(winch, syscall.SIGWINCH)
defer func() { signal.Stop(winch); close(winch) }() // Best effort.

go func() {
	for range winch {
		if err := pty.InheritSize(os.Stdin, ptmx); err != nil {
			log.Printf("resizing pty: %v", err)
		}
	}
}()
winch <- syscall.SIGWINCH // Initial resize.

oldState, err := term.MakeRaw(int(os.Stdin.Fd()))
if err != nil {
	return err
}
defer func() { _ = term.Restore(int(os.Stdin.Fd()), oldState) }() // Best effort.

go func() { _, _ = io.Copy(ptmx, os.Stdin) }()
_, _ = io.Copy(os.Stdout, ptmx)
```

A complete version of this example, with the signal and terminal handling
factored out, is in `example_test.go`.

## Terminal size

`pty.GetSize` reports rows and columns, `pty.GetFullSize` additionally reports
the pixel size when the terminal knows it, and `pty.SetSize` changes the size of
a pty. `pty.InheritSize` copies the size of one terminal to another. The
`Winsize` fields map directly onto the `ws_*` fields of the kernel structure.

## Windows pseudo-consoles

Windows has no pseudo-terminal devices, so the package offers ConPTY instead: a
console host that a process can be attached to and that is driven over a pair of
pipes.

```go
console, err := pty.NewConPTY(pty.DefaultWidth, pty.DefaultHeight, 0)
if err != nil {
	return err
}
defer func() { _ = console.Close() }() // Best effort.

pid, handle, err := console.Spawn("cmd.exe", []string{"cmd.exe", "/c", "echo hello"}, nil)
if err != nil {
	return err
}
defer windows.CloseHandle(windows.Handle(handle)) // The caller owns the handle.

_ = pid
_, err = io.Copy(os.Stdout, console) // console is an io.Reader and an io.Writer.
return err
```

`pty.NewConPTYWithPipes` accepts pipes the caller created with `pty.CreatePipes`
or in any other way, which is useful when the process is started separately.

## Non-blocking I/O

The files returned by this package are ordinary `*os.File` values owned by the
caller. Making `Close` interrupt a concurrent `Read`, or making deadlines work,
requires non-blocking I/O first:

```go
if err := syscall.SetNonblock(int(ptmx.Fd()), true); err != nil {
	return err
}
```

## Development

The `Makefile` has an entry point for everything:

```sh
make          # build, vet and test on the host system
make test     # run the tests
make vet      # run go vet
make fmt      # format the sources
make cross    # compile for every supported GOOS/GOARCH pair
make help     # list all targets
```

The `ztypes_*.go` files, which describe the C types and constants of the BSD
pseudo-terminal interfaces, are generated by `mktypes.bash`; see the comments in
that script. They are the only generated files in the repository and they are
never edited by hand.
